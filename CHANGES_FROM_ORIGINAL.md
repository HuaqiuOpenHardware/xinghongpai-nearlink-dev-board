# Changes From Original Import

This repository records the original downloadable archives in `downloads/MANIFEST.md`.

The extracted firmware examples were lightly sanitized before publishing to GitHub:

- Replaced demo Wi-Fi passwords such as `12345678`, `123456789` and `1234567890` with explicit placeholders.
- Kept the original archive URLs and checksums in `downloads/MANIFEST.md` so the source package can be verified against p.eda.cn.

No hardware source files were modified during the first import.
