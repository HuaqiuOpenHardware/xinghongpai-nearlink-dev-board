# License Notes

This repository is a mixed open hardware / firmware import from the public p.eda.cn project page for "星鸿派-星闪开发板".

## Hardware

The p.eda.cn license field states "CERN Open Hardware License". The specific CERN-OHL variant, such as S, W or P, was not provided in the page metadata captured for this import. Treat hardware redistribution as pending license-version confirmation before manufacturing or publishing modified derivatives.

## Firmware

Many firmware files include Apache License 2.0 headers from HiHope Open Source Organization and HiSilicon. The Apache-2.0 license text is included as `Apache-2.0.txt` when available.

## Original archives and vendor documents

`downloads/MANIFEST.md` records the public p.eda.cn download URLs and SHA256 checksums for the original packages. SDK and vendor documentation archives may contain third-party content; downstream users should follow the upstream terms included in those packages.

## Page inconsistency

The page content also says the project adopts Apache 2.0 for commercial reuse. Because the page-level license field and page body are not fully aligned for hardware licensing, this repository keeps the notices explicit instead of collapsing everything into one license.
