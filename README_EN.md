# Xinghongpai NearLink Development Board

Xinghongpai is a NearLink development board based on the HiSilicon WS63V100 / Hi3863 platform. It supports Wi-Fi, BLE and SLE, and is designed for IoT prototyping, smart home devices, environmental sensing and embedded education.

Original project page: https://p.eda.cn/d-1328625634846441472

This repository contains KiCad hardware sources, BOM, OpenHarmony / Hi3863 example firmware, project images and archived original downloads. See `README.md` and `LICENSES/README.md` for details.
